# BrushLLM

**Your AI, without the complexity.**

One OpenAI-compatible API for powerful AI models,
plus a family of free, local-first desktop apps.

## AI Model Services — one API, every model

A single OpenAI-compatible endpoint for chat, reasoning, vision and
text-to-image models from leading AI labs — DeepSeek, Qwen, GLM, Kimi,
MiniMax, OpenAI and more. Published per-token rates, no subscriptions,
free tiers to start. If it works with the OpenAI SDK, it works with
BrushLLM — change one line and ship.

## Desktop apps — free, local-first, open source

| App | What it does |
| --- | --- |
| [**Image Studio**](https://github.com/BrushLLM/brushllm-image-studio) | Local-first AI image toolbox — free offline tools, AI features via the BrushLLM API |
| [**Video Studio**](https://github.com/BrushLLM/brushllm-video-studio) | Local video, audio & subtitle processing — 100% on your device, zero uploads |
| [**Player**](https://github.com/BrushLLM/brushllm-player) | Open media player built on mpv — every format, plus WebDAV/SMB/Emby/Jellyfin streaming |

macOS (Apple Silicon) and Windows. Nine languages. Zero telemetry,
zero accounts, no ads.

## Principles

- **Honest pricing** — published rates, pay-as-you-go, free tiers that stay free
- **Local-first** — your media and your edits stay on your machine
- **Privacy by design** — no trackers, no analytics, no ads
- **Open source** — the apps and the site are on GitHub
